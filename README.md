# 木客诡事 · Haicheng Mystery

> 一位教授坠崖身亡，夜色里只剩下他没删干净的博客。
> 翻遍他的日记、追问那个自称目击者的画室学生——你查到的每一条线索，都可能是真相的最后一块拼图。

一款以「翻网页、查资料、拼线索」为核心的网页解谜 / 互动叙事作品（ARG 风格）。
纯静态网页，**无需下载、无需登录、无需联网**，进度保存在浏览器本地。

## 在线游玩

**https://<你的用户名>.github.io/muke-guishi/**

（正式地址以仓库 Settings → Pages 为准）

## 玩法

1. 从「校园论坛」进入，逐个查看帖子、私信、公告板；
2. 按提示访问教授的博客、新闻网、相关机构官网；
3. 部分页面需要解谜才能继续（密码锁 / 解码 / 星象符号），线索都藏在前面看过的页面里；
4. 手账本解锁后可回看全部 40 页日记。

约 30-60 分钟。手机与桌面浏览器均可完整通关。

## 内容提示

含突脸惊吓、闪烁画面与低音量背景音效；心脏病、癫痫患者、孕妇及精神敏感人群请谨慎游玩，建议游玩前调低设备音量。
